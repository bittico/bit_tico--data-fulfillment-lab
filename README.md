# Data Fulfillment & Quality Assurance Lab

## Project Overview

This project simulates a real-world Data Fulfillment and Data Quality workflow similar to those used in enterprise environments.

Using a public e-commerce dataset, the project demonstrates data ingestion, SQL querying, data validation, quality assurance, documentation, and reporting processes.

The objective is to build practical experience with technologies and concepts commonly used in Data Operations, Data Fulfillment, and Data Analytics roles.

---

## Dataset Source

Brazilian E-Commerce Public Dataset by Olist

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The original source files are maintained locally and imported into SQL Server. Large datasets are intentionally excluded from the repository.

---

## Project Goals

- Import datasets into SQL Server
- Create and document relational database structures
- Perform SQL queries and joins
- Validate and analyze data quality
- Create and maintain data dictionaries
- Perform data processing using Python
- Export files using different encodings
- Document project activities following Agile principles
